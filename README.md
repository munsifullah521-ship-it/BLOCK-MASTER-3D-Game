# 🎮 BLOCKMASTER3D

**A Premium Lightweight 3D Block Puzzle Game**

BLOCKMASTER3D is a fun, colorful and addictive 3D block puzzle game designed for both mobile and desktop players. Place blocks strategically, clear rows and columns, earn coins and challenge yourself with increasingly difficult levels.

## ✨ Features

- 🎨 Beautiful 3D graphics
- 🧩 Interactive block puzzle gameplay
- 📱 Mobile and desktop support
- 🖱️ Mouse and touchscreen controls
- 🎯 Score and best score tracking
- 🪙 Coin and reward system
- 💡 Hint system
- 🏆 Level progression
- 💾 Automatic game progress saving
- 🔊 Sound effects and settings
- ⚡ Lightweight performance optimization

## 🛠️ Technologies Used

- React
- Vite
- Three.js
- JavaScript
- CSS
- LocalStorage

## 🎮 How to Play

1. Open BLOCKMASTER3D.
2. Press the Play button.
3. Choose one of the available blocks.
4. Drag and place the block on the 8×8 puzzle board.
5. Complete full rows or columns to clear them.
6. Earn points and coins.
7. Keep playing and beat your best score!

## 🚀 Getting Started

### Prerequisites

- Node.js
- npm

### Installation

Clone the repository:

```bash
git clone YOUR_REPOSITORY_URL
```

Go to the project directory:

```bash
cd BLOCKMASTER3D
```

Install dependencies:

```bash
npm install
```

Start development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```
